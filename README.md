# Nexus Systems

Коммерческий B2B-концепт для портфолио: сайт вымышленной инженерной компании, которая проектирует и интегрирует СКУД, видеонаблюдение, пожарную автоматику, СКС и электроснабжение.

> **Важно:** Nexus Systems — вымышленный бренд. Демонстрационные кейсы, названия объектов, цены и расчёты не относятся к реальным заказчикам и не являются коммерческим предложением.

## Что реализовано

- адаптивный одностраничный B2B-сайт;
- шесть смысловых разделов;
- интерактивный подбор решений по типу объекта;
- калькулятор предварительного бюджета;
- перенос результата расчёта в форму заявки;
- демо-форма с валидацией;
- подготовленный API-адаптер для backend-интеграции;
- SEO: title, description, canonical, Open Graph, sitemap;
- доступность: клавиатурная навигация, aria-состояния, reduced motion.

## Стек

HTML5 · CSS3 · Vanilla JavaScript · Responsive UI · REST-ready frontend

Сайт статический и не требует этапа сборки или frontend-зависимостей.

## Локальный запуск

Из корня проекта:

```bash
python -m http.server 4173
```

Затем открыть `http://localhost:4173`.

## Калькулятор

Калькулятор является демонстрационной UX-моделью, а не инженерной сметой. Итог зависит от площади, типа объекта, выбранных систем и условного коэффициента сложности. Показан ориентировочный диапазон ±20%.

## Backend-интеграция

В демо-режиме форма ничего не отправляет и не сохраняет.

Для подключения backend укажите HTTPS endpoint в `config.js`:

```js
window.NEXUS_CONFIG = {
  leadEndpoint: 'https://example.com/api/leads'
};
```

Frontend отправляет POST JSON с данными клиента, описанием задачи и результатом калькулятора. Серверная сторона должна повторно валидировать входные данные, ограничивать частоту запросов, защищаться от спама и самостоятельно пересчитывать коммерческие значения.
